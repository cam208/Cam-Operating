# Cam-Operating — Redstick Ventures Operating System

The versioned source of record for how **Redstick Ventures** runs: thesis, deal
process, portfolio management, LP relations, governance, and the playbooks the team
runs day to day. This repo is the file-backed twin of the Redstick Notion workspace —
Notion holds the live databases and navigation; this repo holds the durable process,
frameworks, and templates under version control.

> **New here? Read [`CLAUDE.md`](./CLAUDE.md) first.** It is the canonical fact sheet
> (fund size, check sizes, thesis, underwriting rules) that every other document defers to.

---

## What Redstick is (one paragraph)

Redstick Ventures is an early-stage VC firm backing **AI and robotics that make food
systems more productive**, farm to consumer. Fund I is **$5M**, writing **$100K or
$250K** checks at pre-seed through Series A across North America, built toward a
**15–20 company** power-law portfolio. Led by GP **Cam Crowder** (former Tim Hortons
franchisee/operator) and co-founder **Shane Larisey** (supply-chain engineering), with
**Olli**, an AI executive assistant, running triage and coordination.

## The four investment vectors

1. **Labour Productivity (Robotics)** — machines replacing manual food labor
2. **Optimization (CV/Sensing)** — vision/sensing for grading, sorting, QC
3. **Decision Automation (AI/Ops)** — forecasting, inventory, scheduling, compliance
4. **Input Efficiency (Bio/Materials)** — materials/bioprocesses for production efficiency

## How to use it

- **Evaluating a deal?** → `skills/deal-triage/SKILL.md` + section 3.
- **Sizing a check / reserve?** → section 4.
- **A portfolio company in trouble?** → section 9 (crisis playbook).
- **LP question or report due?** → section 6.
- **Updating the process itself?** → edit the source file here, then mirror to Notion. See `operating-cadence.md`.

## Maintenance

This is a living system. It drifts out of date the moment the fund changes. See
[`operating-cadence.md`](./operating-cadence.md) for the monthly/quarterly/annual
review rhythm. Fund parameters (deployment, portfolio count, TVPI) are refreshed
monthly.
