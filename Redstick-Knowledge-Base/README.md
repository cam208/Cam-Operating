## The four investment vectors

| Vector | Definition |
|---|---|
| Labour Productivity (Robotics) | Physical systems replacing manual labor in food production/processing/service |
| Optimization (CV/Sensing) | AI vision/sensing for grading, sorting, QC |
| Decision Automation (AI/Ops) | AI automating forecasting, inventory, scheduling, compliance |
| Input Efficiency (Bio/Materials) | Novel materials/bioprocesses improving production efficiency |
