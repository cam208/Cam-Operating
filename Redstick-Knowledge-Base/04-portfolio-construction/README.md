# 4 — Portfolio Construction

The operational mechanics of building the Fund I portfolio: how much to write, how many
names, how much to hold back, and how to concentrate into winners. The strategic "why"
is [`../01-fund-strategy-thesis/03-portfolio-construction-logic.md`](../01-fund-strategy-thesis/03-portfolio-construction-logic.md);
this section is the "how."

## The shape at a glance

| Parameter | Fund I |
|---|---|
| Fund size | $5.0M |
| Initial check | $100K or $250K only |
| Target initial portfolio | 15–20 companies |
| Reserve philosophy | ~half of fund held for follow-on into winners |
| Concentration | No single position dominates; sub-vector overlap monitored |
| Return unit | MOIC; every initial check underwritten to the $5M fund-returner bar |
